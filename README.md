# سازنده اینترو کمیته‌ها (پایتون)

همان کد ویدیوهای ساخته‌شده (سکه، پرتو نور، معرفی تک‌تک اعضا، ظاهر شدن بنر، اسکرول بنر بلند و موزیک هم‌زمان)، فقط عمومی‌شده: بنر را بده، ویدیو بگیر.
از هر بنر دو فایل ساخته می‌شود: `Intro_<نام>.mp4` (با موزیک) و `Intro_<نام>_NoMusic.mp4` (فقط افکت).

## اجرا روی کامپیوتر
نیاز: Python 3.10+، ffmpeg، و (برای فونت فارسی) libraqm / fribidi.
```
pip install -r requirements.txt
python make_intro.py banners/safety.jpg --out videos
python make_intro.py --all banners --out videos
```

## اجرا روی GitHub (بدون کامپیوتر، فقط با گوشی)
1. همه این فایل‌ها را در یک repository آپلود کن (پوشه `.github` هم باید باشد).
2. بنر را در پوشه `banners/` بگذار (مثلاً `banners/legal.jpg`).
3. اگر اسم‌ها خودکار درست نخوانده شدند، کنار بنر فایل هم‌نام `.txt` بگذار (مثال: `banners/safety.txt`).
4. تب **Actions** → «Make intro videos» → **Run workflow**.
5. بعد از چند دقیقه، همان صفحه پایین، بخش **Artifacts** → `intro-videos` را دانلود کن.

## قالب فایل اسم‌ها
```
عنوان: جزئیات اجرایی ایمنی
نام | مدرک | توضیح اختیاری
```
یک خط برای هر عضو، به ترتیب از بالا به پایین بنر.

## نکته‌ها
- لوگو و عکس اعضا خودکار از روی بنر پیدا می‌شوند؛ تعداد اعضا هم از روی بنر تعیین می‌شود.
- بنر بلند (مثل ۹ نفره) خودکار اسکرول می‌شود، بنر معمولی ثابت نشان داده می‌شود.
- بدون فایل `.txt` فقط وقتی OCR فارسی نصب باشد اسم‌ها خوانده می‌شود (روی GitHub نصب می‌شود)؛ نتیجه را بررسی کن.
