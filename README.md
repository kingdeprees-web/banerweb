# سازنده اینترو کمیته‌ها (انجمن سازندگان ذی‌صلاح ارومیه)

## انتشار روی GitHub Pages
1. یک Repository جدید بساز (مثلاً `urmia-intro`).
2. همه فایل‌ها (`index.html`، `detect.js`، `assets/`، `README.md`) را آپلود کن.
3. Settings → Pages → Branch: `main` / `(root)` → Save.
4. بعد از ۱-۲ دقیقه: `https://USERNAME.github.io/urmia-intro/`

## استفاده
- هر بنر کمیته را انتخاب کن (با هر تعداد عضو). لوگو و عکس اعضا خودکار پیدا می‌شوند و تعداد اعضا از روی بنر تعیین می‌شود.
- عنوان کمیته و اسم و مدرک اعضا خودکار خوانده می‌شود (نیاز به اینترنت دارد). حتماً یک بار بررسی و اصلاحشان کن.
- «پیش‌نمایش» یا «ساخت و دانلود ویدیو» (بهتر است در Chrome باز شود).
